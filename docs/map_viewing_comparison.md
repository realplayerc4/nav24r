# 地图查看工具对比

## 📊 两种地图查看方式

你的系统现在有两种查看已保存地图的方式，各有优缺点：

---

## 方式 1: RTAB-Map Database Viewer（2D）⭐ 推荐

### 按钮：**📁 数据库**

### 启动方式
```bash
# 控制面板
点击 "📁 数据库" 按钮

# 命令行
rtabmap-databaseViewer ~/rtabmap_maps/map_20260615_1424.db
```

### 优点
- ✅ **官方工具** - RTAB-Map 自带
- ✅ **离线使用** - 不需要启动 ROS 节点
- ✅ **启动快速** - 直接打开数据库文件
- ✅ **详细信息** - 节点、链接、闭环、图像
- ✅ **质量分析** - 可视化拓扑结构和闭环检测
- ✅ **资源占用少** - 轻量级 GUI 应用

### 缺点
- ⚠️ **2D 视图** - 平面视图，无法多角度观察
- ⚠️ **3D 功能有限** - 3D 显示不如 RViz
- ⚠️ **无实时数据** - 不能看到实时建图过程

### 适用场景
- ✅ **地图质量分析** - 查看闭环、节点分布 ⭐⭐⭐
- ✅ **问题诊断** - 检查建图问题 ⭐⭐⭐
- ✅ **快速查看** - 快速打开地图 ⭐⭐⭐
- ✅ **导出截图** - 用于文档和报告 ⭐⭐

---

## 方式 2: RViz 3D 地图观察器（3D）⭐ 视觉效果好

### 按钮：**👁️ 查看地图**

### 启动方式
```bash
# 控制面板
点击 "👁️ 查看地图" 按钮

# 命令行
# 1. 启动 RTAB-Map 定位模式
ros2 launch factor_perception factor_perception_launch.py \
    localization:=true \
    database_path:=~/rtabmap_maps/map_20260615_1424.db

# 2. 启动 RViz
rviz2 -d ~/nav24r/config/map_viewer_3d.rviz
```

### 优点
- ✅ **3D 多视角** - Orbit、顶视角、侧视角等
- ✅ **点云可视化** - 3D 点云地图
- ✅ **Octomap 3D** - 体素网格显示
- ✅ **高度着色** - 按高度彩虹色编码
- ✅ **自由观察** - 旋转、缩放、平移
- ✅ **多图层** - 点云、Octomap、2D 地图、轨迹

### 缺点
- ⚠️ **需要 ROS** - 需要启动 RTAB-Map 节点
- ⚠️ **启动较慢** - 需要等待节点启动和地图加载
- ⚠️ **资源占用大** - ROS 节点 + RViz
- ⚠️ **无节点信息** - 不能查看节点详细数据
- ⚠️ **无闭环可视化** - 不能显示链接关系

### 适用场景
- ✅ **3D 观察** - 多角度立体观察 ⭐⭐⭐
- ✅ **展示演示** - 视觉效果好 ⭐⭐⭐
- ✅ **空间感知** - 理解 3D 空间结构 ⭐⭐⭐
- ✅ **导航准备** - 观察可行走区域 ⭐⭐

## 🎯 推荐使用策略

### 场景 1: 建图完成后的质量分析 ⭐⭐⭐

**推荐：Database Viewer**

```
步骤：
1. 点击 "📁 数据库"
2. 查看 2D 地图
3. 观察闭环检测（绿色/黄色线条）
4. 检查节点分布
5. 导出统计信息
```

**为什么？**
- 快速启动
- 详细信息
- 闭环可视化
- 专业分析功能

---

### 场景 2: 3D 空间理解和展示 ⭐⭐⭐

**推荐：RViz 3D**

```
步骤：
1. 点击 "👁️ 查看地图"
2. 等待地图加载
3. 使用鼠标旋转观察
4. 切换不同视角预设
5. 启用/禁用不同图层
```

**为什么？**
- 多角度观察
- 视觉效果好
- Octomap 3D
- 高度着色

---

### 场景 3: 快速检查地图 ⭐⭐

**推荐：Database Viewer**

```
步骤：
1. 点击 "📁 数据库"
2. 快速浏览地图覆盖范围
3. 检查是否有明显问题
4. 关闭（用时 < 30秒）
```

**为什么？**
- 启动最快
- 离线使用
- 资源占用少

---

### 场景 4: 导航前准备 ⭐⭐

**推荐：两种都用**

```
1. 先用 Database Viewer 检查质量
2. 再用 RViz 3D 观察可行走区域
```

## 💡 使用建议

### 日常工作流

#### 建图完成后
```
1. 点击 "📁 数据库" → 快速质量分析
2. 观察闭环和节点分布
3. 如果质量良好 → 点击 "👁️ 查看地图" → 3D 观察
4. 如果质量不好 → 重新建图
```

#### 导航前
```
1. 点击 "📁 数据库" → 检查地图质量
2. 点击 "👁️ 查看地图" → 3D 观察环境
3. 点击 "🧭 开始导航" → 开始导航
```

#### 问题诊断
```
1. 点击 "📁 数据库" → 详细分析
2. 查看节点详细信息
3. 检查闭环缺失区域
4. 导出问题截图
```

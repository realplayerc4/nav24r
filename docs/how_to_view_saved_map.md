# 如何查看已保存的地图

## 问题说明

**问题**: RViz 只是实时显示话题数据，不能直接加载 `.db` 数据库文件。

**原因**: RTAB-Map 地图数据存储在数据库中，需要通过 RTAB-Map 节点加载并发布到 ROS 话题。

---

## ✅ 解决方案

我已经在控制面板中添加了 **"👁️ 查看地图"** 功能。

---

## 🚀 使用方法

### 方法 1: 控制面板（推荐）⭐

```
1. 打开控制面板
2. 在"已有地图"下拉列表中选择地图（如 map_20260615_1424）
3. 点击 "👁️ 查看地图" 按钮
4. 等待几秒钟，系统会自动：
   - 启动 RTAB-Map 定位模式（加载地图数据）
   - 启动 RViz 地图观察器（显示地图）
```

### 方法 2: 命令行

```bash
# 1. 启动 Factor Perception 定位模式（加载地图）
ros2 launch factor_perception factor_perception_launch.py \
    localization:=true \
    database_path:=~/rtabmap_maps/map_20260615_1424.db \
    key:=12D0C1E7D1AB466C09BD9AE6427D5240

# 2. 在另一个终端启动 RViz
rviz2 -d /home/yq/nav24r/config/map_viewer_3d.rviz
```

## ⚙️ 技术细节

### RTAB-Map 定位模式

启动命令：
```bash
ros2 launch factor_perception factor_perception_launch.py \
    localization:=true \  # 定位模式（只读地图）
    database_path:=<地图路径>
```

**定位模式特点**:
- ✅ 加载已有地图
- ✅ 不添加新节点到地图
- ✅ 在地图中定位机器人
- ✅ 发布地图数据到话题

### 话题数据

查看地图时，以下话题会被发布：

| 话题 | 类型 | 说明 |
|------|------|------|
| `/factor_perception/cloud_map` | PointCloud2 | 3D 点云地图 |
| `/factor_perception/map` | OccupancyGrid | 2D 占用地图 |
| `/factor_perception/octomap_binary` | Octomap | 3D Octomap |
| `/factor_perception/localization_pose` | PoseStamped | 定位位姿 |

## ❓ 常见问题

### Q1: 点击后没有反应？

**可能原因**:
- 地图文件损坏
- ROS 环境未加载

**解决方法**:
```bash
# 检查地图文件
ls -lh ~/rtabmap_maps/map_20260615_1424.db

# 手动测试
source /opt/ros/jazzy/setup.bash
ros2 launch factor_perception factor_perception_launch.py ...
```

### Q2: RViz 显示空白？

**可能原因**:
- 地图数据未完全加载
- 需要等待几秒钟

**解决方法**:
- 等待 5-10 秒让地图完全加载
- 检查话题是否有数据：`ros2 topic list`

### Q3: 地图太大加载慢？

**解决方法**:
```
1. 等待更长时间
2. 检查数据库大小：
   ls -lh ~/rtabmap_maps/*.db
3. 大地图可能需要 10-30 秒加载
```

### Q4: 如何关闭查看模式？

**解决方法**:
- 点击控制面板的 "⏹️ 停止" 按钮
- 会自动停止 RTAB-Map 和 RViz

## 📝 注意事项

### 资源占用

查看地图时会启动：
- ✅ RTAB-Map 节点（加载地图）
- ✅ RViz（显示地图）
- ✅ Factor Perception 相关节点

**建议**:
- 查看完地图后及时停止
- 避免同时查看多个地图

### 地图文件安全

- ✅ 查看模式只读，不会修改地图
- ✅ 可以放心查看而不用担心数据损坏

# RTAB-Map Database Viewer 使用指南

## 📊 工具介绍

**rtabmap-databaseViewer** 是 RTAB-Map 官方提供的地图数据库查看器，专门用于查看和分析已保存的 `.db` 地图文件。

---

## ✨ 主要特点

### 优点
- ✅ **官方工具** - RTAB-Map 自带，功能完整
- ✅ **2D 视图** - 清晰的平面地图显示
- ✅ **详细信息** - 节点、链接、闭环等详细数据
- ✅ **离线使用** - 不需要启动 ROS，直接打开数据库
- ✅ **轻量级** - 启动快，占用资源少
- ✅ **分析功能** - 查看节点信息、图像、3D 点云等

---

## 🚀 使用方法

### 方法 1: 控制面板（推荐）⭐

```
1. 打开控制面板
2. 在"已有地图"下拉列表中选择地图
   例如: map_20260615_1424 (190.0MB)
3. 点击 "📁 数据库" 按钮
4. RTAB-Map Database Viewer 自动启动并加载地图
```

### 方法 2: 命令行

```bash
# 查看默认地图
rtabmap-databaseViewer ~/rtabmap.db

# 查看指定地图
rtabmap-databaseViewer ~/rtabmap_maps/map_20260615_1424.db

# 查看所有可用选项
rtabmap-databaseViewer --help
```

### 关键功能

#### 1. 地图视图（左侧）
- **节点显示**: 每个小方块代表一个关键帧节点
- **链接关系**: 线条表示节点之间的连接
- **颜色编码**:
  - 🔵 蓝色: 邻居链接（连续路径）
  - 🟢 绿色: 全局闭环
  - 🟡 黄色: 局部闭环
  - 🔴 红色: 虚拟链接

#### 2. 节点信息（右侧）
点击地图中的节点可以查看：
- RGB 彩色图像
- 深度图像
- 3D 点云（可选）
- 特征点匹配
- 位姿信息
- 时间戳

## 🔧 常用操作

### 基本操作

| 操作 | 方法 |
|------|------|
| **平移地图** | 鼠标左键拖动 |
| **缩放** | 鼠标滚轮 |
| **选择节点** | 鼠标左键点击 |
| **查看节点详情** | 双击节点 |
| **显示/隐藏链接** | View 菜单 |
| **导出图像** | File → Export |

### 菜单功能

#### File 菜单
- **Open**: 打开其他地图数据库
- **Export**: 导出地图为图像（PNG/PDF）
- **Close**: 关闭当前数据库

#### View 菜单
- **Show Graph**: 显示/隐藏拓扑图
- **Show Scans**: 显示/隐藏激光扫描
- **Show 3D Map**: 显示 3D 点云地图
- **Show Depth**: 显示深度图像

#### Tools 菜单
- **Detect More Loops**: 尝试检测更多闭环
- **Optimize Graph**: 优化图结构
- **Statistics**: 查看统计信息

## 📊 地图质量分析

### 1. 查看闭环检测

```
在 2D 视图中：
- 绿色线条 = 全局闭环（好！）
- 黄色线条 = 局部闭环
- 蓝色线条 = 邻居链接

闭环越多，地图质量越好！
```

### 2. 检查节点分布

```
节点应该：
✅ 均匀分布（覆盖整个区域）
✅ 密度适中（不要太稀疏）
✅ 有足够的重叠（便于闭环）
```

### 3. 查看统计信息

```
Tools → Statistics
显示：
- 节点总数
- 链接总数
- 闭环数量
- 地图尺寸
- 平均密度
```

## 💡 使用技巧

### 技巧 1: 快速定位问题

```
1. 打开地图
2. 查看绿色闭环线条
3. 如果很少闭环，说明：
   - 建图路径可能过于线性
   - 需要增加重访区域
```

### 技巧 2: 导出地图截图

```
File → Export → PNG/PDF
用于：
- 文档记录
- 问题报告
- 地图对比
```

### 技巧 3: 查看特定节点

```
1. 在地图上点击节点
2. 右侧显示详细信息
3. 查看该位置的图像和点云
```

### 技巧 4: 检测更多闭环

```
Tools → Detect More Loops
- 尝试在已有数据中找到更多闭环
- 提高地图质量
- 注意：可能需要较长时间
```

## ⚠️ 注意事项

### 1. 数据库锁定
- 打开数据库时会锁定文件
- 不要同时用多个工具打开同一数据库
- 关闭查看器后才能进行其他操作

### 2. 大地图处理
- 大地图（>200MB）可能加载较慢
- 需要等待完全加载后再操作
- 可以调整显示密度提高性能

### 3. 数据安全
- 查看器默认只读
- "Optimize Graph" 会修改数据库
- 建议在修改前备份数据库

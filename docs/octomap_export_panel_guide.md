## 📋 导出流程详解

### 自动导出的 7 个步骤

| 步骤 | 进度 | 说明 | 预估时间 |
|------|------|------|---------|
| **步骤 1** | 5% | 分析数据库结构 | ~2秒 |
| **步骤 2** | 10% | 启动 RTAB-Map 定位模式 | ~3秒 |
| **步骤 3** | 20-50% | 等待地图加载 | ~20-30秒 |
| **步骤 4** | 50-60% | 检查 Octomap 话题 | ~5秒 |
| **步骤 5** | 60-80% | 捕获 Octomap 数据 | ~10秒 |
| **步骤 6** | 80-90% | 保存 Octomap 文件 | ~3秒 |
| **步骤 7** | 90-100% | 清理进程和验证 | ~2秒 |

### 时间预估公式

```
预估导出时间 = 基础加载时间 + 数据处理时间 × 分辨率系数

具体计算:
  基础加载: 20秒
  数据处理: 文件大小(MB) × 0.5秒
  分辨率系数: 1 / 分辨率值

示例 (190MB, 0.02m):
  = 20 + 190 × 0.5 × 50
  = 20 + 95 × 50
  = 20 + 25
  ≈ 45秒
```

### 不同分辨率的适用场景

| 分辨率 | 体素大小 | 精度 | 文件大小 | 适用场景 | 推荐度 |
|-------|---------|------|---------|---------|--------|
| **0.01m** | 1cm | 超高 | 大 | 工业应用、精细操作 | ⭐⭐ |
| **0.02m** | 2cm | 高 | 中 | 人形机器人导航 | ⭐⭐⭐⭐⭐ |
| **0.05m** | 5cm | 标准 | 小 | 通用导航 | ⭐⭐⭐⭐ |
| **0.10m** | 10cm | 低 | 很小 | 快速规划 | ⭐⭐⭐ |

## ⚠️ 注意事项

### 1. 导出过程中的提示

如果自动导出遇到问题，会提示：

```
⚠️ 自动导出需要额外的 ROS 工具

推荐使用 GUI 方法导出:
  rtabmap-databaseViewer <数据库路径>
  File → Export 3D clouds → Octomap

这是最可靠的导出方法！
```

### 2. 导出失败的可能原因

- RTAB-Map 进程启动失败
- 地图文件过大，加载超时
- Octomap 话题未发布
- ROS2 环境问题

### 3. 备用方案

如果自动导出失败，建议使用：

```
RTAB-Map Database Viewer (GUI):

步骤 1: rtabmap-databaseViewer ~/rtabmap_maps/map.db
步骤 2: File → Export 3D clouds...
步骤 3: 选择 Octomap
步骤 4: 设置分辨率 0.02m
步骤 5: Export

优点:
✅ 最可靠
✅ 可视化效果好
✅ 支持多种导出格式
```

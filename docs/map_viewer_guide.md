# 地图观察器使用指南

## 🗺️ 地图观察器介绍

**地图观察器** 是一个专门用于查看和分析已建好地图的 RViz 配置文件。它不依赖实时数据，可以单独启动用于地图质量分析。

---

## 📁 文件位置

**配置文件**: `/home/yq/nav24r/config/map_viewer_3d.rviz`

---

## 🚀 启动方式

### 方法 1: 控制面板（推荐）

点击 **"🗺️ 地图观察"** 按钮

### 方法 2: 命令行

```bash
rviz2 -d /home/yq/nav24r/config/map_viewer_3d.rviz
```

## ✨ 主要功能

### 1. 多层次地图显示

| 显示层 | 说明 | 颜色/样式 |
|--------|------|-----------|
| **3D 点云地图** | 完整的点云数据 | 按高度着色（彩虹色）|
| **障碍物点云** | 障碍物区域 | 红色方块 ⭐ |
| **地面点云** | 可行走区域 | 绿色点 |
| **Octomap 3D** | 3D 占用网格 | 高度着色方块 |
| **2D 占用地图** | 传统 2D 地图 | 灰度地图 |

### 2. 机器人轨迹显示

- ✅ 显示机器人运动轨迹
- ✅ 黄色路径线
- ✅ 实时位姿箭头

### 3. 多视角预设

| 视角名称 | 用途 | 快捷切换 |
|---------|------|----------|
| **顶视角（正交）** | 平面视图 | Views → Saved → 双击 |
| **侧面全景** | 整体观察 | 同上 |
| **前视角观察** | 前方观察 | 同上 |
| **高空俯瞰** | 全局视图 | 同上 |
| **近景细节** | 局部细节 | 同上 |
| **环绕视角** | 360° 观察 | 同上 |

## 🎮 操作方法

### 视角操作

| 操作 | 鼠标/键盘 | 说明 |
|------|-----------|------|
| **旋转** | 鼠标左键拖动 | 围绕焦点旋转 |
| **平移** | 鼠标中键 / Shift+左键 | 平移视图 |
| **缩放** | 鼠标滚轮 / 右键拖动 | 放大缩小 |
| **重置** | 按 `r` 键 | 重置视角 |

### 切换显示层

在左侧 Displays 面板中：
- ✅ 勾选 = 显示
- ☐ 取消 = 隐藏

### 切换预设视角

1. 展开 **Views** → **Saved Views**
2. 双击想要切换的视角
3. 视角会自动切换

## 📊 显示效果对比

### 顶视角 vs 3D 视角

| 视角 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **顶视角** | 平面视图清晰 | 无法看高度 | 路径规划 |
| **3D 视角** | 空间感知强 | 复杂度高 | 地图分析 |

### 点云 vs Octomap

| 显示方式 | 优点 | 缺点 | 适用场景 |
|---------|------|------|----------|
| **点云** | 细节丰富 | 数据量大 | 精细观察 |
| **Octomap** | 结构清晰 | 细节丢失 | 结构分析 |

## 🔧 高级功能

### 1. 自定义视角

调整到满意的视角后保存：

1. 调整视角
2. Views → Save Current View
3. 输入名称
4. 以后可快速切换

### 2. 测量距离

使用测量工具：

1. 点击工具栏"Measure"工具
2. 在地图上点击两点
3. 显示距离

### 3. 聚焦对象

选中对象并聚焦：

1. 点击"FocusCamera"工具
2. 点击地图上的对象
3. 视角自动聚焦

## ❓ 常见问题

### Q: 地图观察器能单独启动吗？

**A**: 可以！地图观察器不需要建图进程运行，只要话题有数据即可。

### Q: 为什么有些显示层没有数据？

**A**: 需要启动 Factor Perception 或加载地图数据。确保建图或导航模式正在运行。

### Q: 如何保存当前视角？

**A**: Views → Save Current View，输入名称保存。

### Q: 地图观察器会影响性能吗？

**A**: 会有一定影响。如果卡顿，可以：
- 降低显示帧率
- 隐藏部分显示层
- 增大点云大小
